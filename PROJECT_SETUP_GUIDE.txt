QUOTATION GENERATOR PROJECT GUIDE
=================================

Project Overview
----------------
This project is a full-stack quotation management application with:
- Frontend: React + Vite + Tailwind CSS
- Backend: FastAPI + SQLAlchemy + PostgreSQL
- Authentication: JWT-based login and registration
- Functionality: quotation generation, PDF preview, company/customer details, product and item management

Prerequisites
-------------
Install the following on your machine:

1. Python 3.11+
2. Node.js 18+
3. PostgreSQL 14+
4. npm
5. pip
6. Git (optional but recommended)

Required local tools:
- VS Code (recommended)
- PostgreSQL client tools or pgAdmin (optional)

Database Setup
--------------
1. Create a PostgreSQL database named:
   quotation_db

2. Set up the database user and password if needed.

3. Update the backend .env file at:
   backend/backend/.env

   Example:
   DATABASE_URL=postgresql+asyncpg://postgres:your_password@localhost:5432/quotation_db
   SECRET_KEY=your_secret_key
   JWT_SECRET_KEY=your_jwt_secret_key
   ALGORITHM=HS256

4. Make sure PostgreSQL is running locally.

5. The backend startup process will create tables automatically if the database is reachable.

Python Backend Setup
--------------------
1. Open a terminal.
2. Go to the backend folder:
   cd backend/backend
3. Create and activate a virtual environment (recommended):
   python -m venv venv
   venv\Scripts\activate
4. Install dependencies:
   pip install -r requirements.txt
5. If needed, install PostgreSQL driver separately:
   pip install asyncpg

Start Backend
-------------
From the backend folder:

cd backend/backend
venv\Scripts\activate
py -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Backend should start at:
http://127.0.0.1:8000

Optional health check:
http://127.0.0.1:8000/health

Important Note on Local Development
----------------------------------
The frontend is configured to call the backend through Vite proxy and local API routes.
After starting both services, open the UI and log in using the backend users.

Authentication Flow
-------------------
The app uses a login form that sends username and password to the backend:
- Endpoint: /auth/login
- Method: POST
- Content-Type: application/x-www-form-urlencoded

Example login credentials created during local validation:
- Username: adminuser1
- Password: Password123!

Role and User Creation
----------------------
The backend auto-seeds default roles when it starts, including:
- Super Admin
- Admin
- Manager
- Sales
- Viewer

You can create additional users through the API or by using the app registration flow.

Troubleshooting
---------------
1. Port 8000 already in use:
   - Stop the previous backend process and restart it.

2. Port 3001 already in use:
   - Stop the previous frontend process and restart it.

3. Invalid credentials:
   - Check that the user exists in PostgreSQL.
   - Confirm the username and password are correct.
   - Restart backend after database setup changes.

4. CORS issues:
   - Ensure the frontend URL is included in the FastAPI CORS middleware config.

5. Database connection errors:
   - Check your PostgreSQL username, password, host, port, and database name.
   - Confirm PostgreSQL is running.
