Quotation Generator - Local Run Instructions
=============================================

These commands are for Windows PowerShell from this repository:
C:\Users\kilap\IdeaProjects\bhanuGibbs

Requirements
------------
- Python 3.12 or later
- Node.js 18 or later and npm

Backend
-------
Open PowerShell and run:

  Set-Location C:\Users\kilap\IdeaProjects\bhanuGibbs\backend\backend
  py -m venv venv
  .\venv\Scripts\Activate.ps1
  python -m pip install -r requirements.txt


  Set-Location C:\Users\kilap\IdeaProjects\bhanuGibbs\backend\backend
  $env:PYTHONPATH = (Get-Location).Path
  .\venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

Keep this PowerShell window open. The development database is created as
backend\backend\quotation.local.db. This fresh local database avoids changing
the repository's existing quotation.db. The DATABASE_URL environment setting
overrides the value in backend\backend\.env. For a deployed environment, use a
managed database and a securely generated JWT secret rather than the example
values. A fresh database starts empty; register an account and complete the
company profile after running the migrations. Data in another database is not
copied automatically. If you delete this local database, its accounts and
documents are removed as well.

Check the backend:
- API health: http://127.0.0.1:8000/health
- Interactive API docs: http://127.0.0.1:8000/docs

Frontend
--------
Open a second PowerShell window:

  Set-Location C:\Users\kilap\IdeaProjects\bhanuGibbs
  npm install
  npm run dev -- --host 127.0.0.1 --port 3001

Open http://127.0.0.1:3001, register an account, then complete the company
profile. New public registrations receive the Sales role; role changes are not
available from profile settings. The authenticated user can edit their own
username, email, and mobile number from My profile.

Migrations
----------
When backend database migrations are added, run this in the backend PowerShell
window with the same DATABASE_URL set:

  $env:PYTHONPATH = (Get-Location).Path
  .\venv\Scripts\alembic.exe upgrade head

The application scopes quotation, customer, product, and profile operations to
the authenticated user. Existing customer/product rows without an owner are
not exposed through user-scoped lists or quotation creation.

Quotation testing and numbering
-------------------------------
Create a quotation from the UI or POST a draft to /quotations/draft. Draft
references are temporary; finalizing a quotation assigns its permanent,
unique number using the issue date and daily sequence (for example,
QT-09082026-001 for 9 August 2026). Billing documents use the INV prefix.
The quotation list and PDF download are available only to the owning account.

Production build
----------------
From the repository root:

  npm run build

Cloud deployment

For step-by-step instructions to deploy the frontend to Vercel, the backend
